# Security

This is research code that reads local CSV files and writes local artefacts; it opens no network connections and
handles no credentials. The Kaggle CLI commands in the documentation use your own Kaggle token, which never belongs
in this repository.

If you find a problem (for example a dependency with a known vulnerability, or a file that should not have been
published), please open a private security advisory on GitHub or email agnuxo1@gmail.com instead of a public issue.
